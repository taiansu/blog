# Try survive in vim

總有些時候會聊到編輯器跟 Vim，對於剛學程式的人，我還是都建議先用些直覺的工具。直到有天你要直接 ssh 進伺服器改東西時，再來學也不遲。否則一下要適應一堆東西，有時候挫折感太多，會弄壞學習的胃口。


## 1. 先花 40 分鐘把內建的教學做過一次。

## 2. 你肯定需要一個插件管理器
  不管是 Pathogen、Vundle 還是 VAM，都可以讓你不用再麻煩的下載刪除更新。
