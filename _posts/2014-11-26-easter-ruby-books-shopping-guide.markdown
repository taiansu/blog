# [Pragmatic Bookshelf](https://pragprog.com/)

> Discount Code: turkey2014  
> Discount: 50% for all ebooks  
> End date: Dec 1, 2014  

###1. [Confident Ruby](https://pragprog.com/book/agcr/confident-ruby)
推薦指數: ☆☆☆☆☆ (必買)

這本書列出數十種如何寫出漂亮乾淨的 Ruby code 手法及準則。在我心中地位如同 [Kent Beck 實作模式](http://www.books.com.tw/products/0010611737)的 Ruby 版。

###2. [Exceptional Ruby: Master the Art of Handling Failure in Ruby](https://pragprog.com/book/ager/exceptional-ruby)
推薦指數: ☆☆☆☆

###3. [Metaprogramming Ruby 2: Program Like the Ruby Pros](https://pragprog.com/book/ppmetr2/metaprogramming-ruby-2)
推薦指數： ☆☆☆

我比較喜歡 Dave Thomas 這個 [The Ruby Object Model and Metaprogramming](https://pragprog.com/screencasts/v-dtrubyom/the-ruby-object-model-and-metaprogramming) 影片，但是似乎沒有特價。

###4. [Crafting Rails 4 Applications](https://pragprog.com/book/jvrails2/crafting-rails-4-applications)
推薦指數： ☆☆☆

Elixir 語言作者寫的好書，分析 Rails 內部如何運作。喜歡 meta-programming
的話，可以從這本裡看到許多實際上的用法。當然也比較進階一點。

###5. [Build Awesome Command-Line Applications in Ruby: Control Your Computer, Simplify Your Life](https://pragprog.com/book/dccar/build-awesome-command-line-applications-in-ruby)
推薦指數： ☆☆☆

試試 Ruby 除了 Web 還可以幹啥的好起點。

除此之外，[Programming Ruby](), [Agile Web Development with Rails 4]()，[The RSpec Book]()
這種有一陣子的參考書就看個人想不想收了。

PS: 跟 Ruby 不那麼有關的，我想偷推一下 [Programming Elixir](https://pragprog.com/book/elixir/programming-elixir) ♥♥♥♥♥

另加三本 Working with 系列基礎書：

* [Working with Unix processes](https://pragprog.com/book/jsunix/working-with-unix-processes)
* [Working with Ruby Threads](https://pragprog.com/book/jsthreads/working-with-ruby-threads)
* [Working with tcp sockets](https://pragprog.com/book/jstcp/working-with-tcp-sockets)

# [InformIT](http://www.informit.com/)

> Discount Code: BF2014  
> Discount: Buy 1 save 35%, 2 or more for 50%  
> End date: 沒說，應該就到本週五吧？  

###1. [Practical Object-Oriented Design in Ruby: An Agile Primer](http://www.informit.com/store/practical-object-oriented-design-in-ruby-an-agile-primer-9780321721334)
推薦指數: ☆☆☆☆☆ (必買)

Object oriented 其實可以很輕巧，很靈活，很愉快。不是一大堆 UML 跟繁雜的大設計 ( 我不會說是什麼語言給我們這種印象 )。這本書說明各種設計的問題，並介紹 OO 裡的準則，並用簡單的 Ruby 實現。直指 Smalltalk 精神的 OO 觀念佳作。如果你只看一本教 OO 的書，那就選它吧。

###2. [Eloquent Ruby](http://www.informit.com/store/eloquent-ruby-9780321584106)
推薦指數: ☆☆☆☆

###3. [Refactoring: Ruby Edition: Ruby Edition](http://www.informit.com/store/refactoring-ruby-edition-ruby-edition-9780321984135)
推薦指數: ☆☆☆☆

如果你有 Java 版的話，那就不用多買。如果你看得懂 Java，那中文版比較便宜。 XD


###4. [Effective Ruby: 48 Specific Ways to Write Better Ruby](http://www.informit.com/store/effective-ruby-48-specific-ways-to-write-better-ruby-9780133846973)

這本我買了還沒翻開過…

[Design Patterns in Ruby](http://www.informit.com/store/design-patterns-in-ruby-9780321490452)，[Rails 4 Way](http://www.informit.com/store/rails-4-way-9780321944276) 就看個人需求了。
