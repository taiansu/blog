### Bash Hotkeys

* <kbd>control</kbd> + <kbd>A</kbd> : move cursor to line start.

* <kbd>control</kbd> + <kbd>E</kbd> : move cursor to line end.

* <kbd>control</kbd> + <kbd>U</kbd> : clears the line content.

* <kbd>control</kbd> + <kbd>L</kbd> : clears the screen content.

* <kbd>control</kbd> + <kbd>W</kbd> : cut the word before cursor.

* <kbd>option</kbd> + <kbd>D</kbd> : cut the word after cursor.

* <kbd>option</kbd> + <kbd>F</kbd> : move the cursor *forward* one word.

* <kbd>option</kbd> + <kbd>B</kbd> : move the cursor *backward* one word.

Note : In iTerm2, you have to set <kbd>option</kbd> work as '+Esc' in 'Preference → profile' for moveing cursor, otherwise it will send the special characters.

### Page Up / 上一頁

<kbd>Fn</kbd> + <kbd>↑</kbd>

### Page Down / 下一頁

<kbd>Fn</kbd> + <kbd>↓</kbd>

### Home

<kbd>Fn</kbd> + <kbd>←</kbd>

### End

<kbd>Fn</kbd> + <kbd>→</kbd>

---

### Move cursor to end of line / 移動游標至行尾

<kbd>command</kbd> + <kbd>→</kbd> or
<kbd>control</kbd> + <kbd>A</kbd>(bash hotkey)

In most of the cases, the first one should do the job. But in some application which the first key-binding maps to something else, e.g. iTerm2, you have to use the bash hotkeys.

### Move cursor to begin of line / 移動游標至行頭

<kbd>command</kbd> + <kbd>←</kbd> or
<kbd>control</kbd> + <kbd>E</kbd>(bash hotkey)

### Select content from cursor to begin of line / 選取游標至行頭的內容

<kbd>command</kbd> +  <kbd>shift</kbd> + <kbd>←</kbd>

### Select content from cursor to end of line / 選取游標至行尾的內容

<kbd>command</kbd> +  <kbd>shift</kbd> + <kbd>→</kbd>

---

### Open file/application / 開啟檔案/程式

<kbd>command</kbd> + <kbd>O</kbd> or

<kbd>command</kbd> + <kbd>↓</kbd>

---

### Hide/Show the dock from screen. / 顯示/隱藏下方 Dock

<kbd>command</kbd> + <kbd>option</kbd> + <kbd>D</kbd> or

<kbd>control</kbd> + <kbd>F3</kbd>

---

### Cycle through windows in current application. /  在同一應用程式的不同視窗中循環切換

For example, if you open servel windows of Chrome Browser, this hotkey will focus on each window iterately.

舉例來說，假設你在 Chrome 瀏覽器中開了數個視窗，此熱鍵會在輪流將各個視窗設為目標視窗。

<kbd>command</kbd> + <kbd>`</kbd>

> ps: <kbd>`</kbd> Backtick, or grave accent, which is above <kbd>Tab</kbd> key.

><kbd>`</kbd>抑音符位置在<kbd>Tab</kbd>鍵的上方.

---

### Turn cureent application to "Full screen mode" / 將目前的應用程式切換為"全螢幕模式" (Above Lion)

<kbd>command</kbd> + <kbd>control</kbd> + <kbd>F</kbd>

---

### Search this word in Dictionary.app / 在字典中查詢目前單字 (Above Lion)

Select the word first, then press:
<kbd>command</kbd> + <kbd>control</kbd> + <kbd>D</kbd>
> ps: Might not work in some applications.

先圈選想查詢的單字，接著按下:
<kbd>command</kbd> + <kbd>control</kbd> + <kbd>D</kbd>
> ps: 在某些應用程式下無法使用
